# Ourobask

แอป Flutter สำหรับเก็บ **Task / Work / Idea** พร้อมระบบแจ้งเตือนและปลุกตามกำหนดส่ง
ข้อมูลทั้งหมดเก็บในเครื่องด้วย **SQLite** และ Export / Import เป็นไฟล์ JSON ได้

## ความสามารถ

### งาน (Task)
- สร้างงานได้เหมือนโน้ต มีชื่อเรื่อง + รายละเอียด
- **วันที่และเวลาเป็นทางเลือกทั้งคู่**
  - ไม่ระบุวัน → เป็นงานไม่มีกำหนดส่ง
  - ระบุวันแต่ไม่ระบุเวลา → นับเป็น **ทั้งวัน (all-day)** และใช้ 09:00 เป็นเวลาอ้างอิงของการเตือน
  - ระบุเวลาด้วย → กำหนดระยะเวลาของงานเพิ่มได้
- ระดับความสำคัญ สี และสถานะเสร็จสิ้น

### โฟลเดอร์งาน (Work Project)
- สร้างโปรเจกต์เป็นโฟลเดอร์ครอบงานอีกชั้น เลือกไอคอนและสีได้
- หน้า **งาน** แสดงโปรเจกต์เป็น card view พร้อมความคืบหน้าและจำนวนงานที่ค้าง
- ลบโฟลเดอร์ได้ทั้งแบบเก็บงานไว้หรือลบงานไปพร้อมกัน

### การแจ้งเตือนและปลุก
- ตั้งเตือนล่วงหน้าได้หลายรายการต่อหนึ่งงาน เช่น ก่อน 1 ชั่วโมง / 1 วัน / 1 สัปดาห์ หรือกำหนดเองเป็นนาที
- แต่ละการเตือนเลือกได้ว่าเป็น **แจ้งเตือนธรรมดา** หรือ **ปลุก (alarm)**
- ปลุกเลือกเสียงจากเครื่องผู้ใช้ได้ 2 ทาง
  - เสียงในระบบ (ตัวเลือกเสียงมาตรฐานของ Android)
  - ไฟล์เสียงในเครื่อง — ไฟล์จะถูกคัดลอกเข้าโฟลเดอร์แอปและแปลงเป็น `content://` ผ่าน FileProvider เพื่อให้ระบบแจ้งเตือนอ่านได้
- ลองฟังเสียงก่อนใช้จริงได้ (เล่นด้วยระดับเสียงของ alarm)
- **หน้าแรกมีสวิตช์เปิด/ปิดการเตือนแต่ละรายการได้อิสระ โดยไม่ต้องลบการเตือนทิ้ง**

### หน้าแรก
เรียงงานตามความใกล้ของกำหนดส่ง แบ่ง Section ตามลำดับ

1. เลยกำหนดแล้ว
2. ครบกำหนดวันนี้
3. ภายใน 1 วัน
4. ภายใน 3 วัน
5. ภายใน 1 สัปดาห์
6. ภายใน 2 สัปดาห์
7. ภายใน 1 เดือน
8. มากกว่า 1 เดือน
9. กิจวัตรที่ทำซ้ำ + งานที่ไม่มีกำหนดส่ง

ด้านบนมีกล่องรวม **การแจ้งเตือน & ปลุก** ทั้งหมดพร้อมสวิตช์เปิด/ปิด

### ปฏิทิน (View)
- **สัปดาห์** — ตารางเวลาแบบตารางเรียน มีหลักชั่วโมง 00:00–23:00 งานที่เวลาทับกันจะแสดงเคียงกัน มีแถวงานทั้งวันด้านบนและเส้นบอกเวลาปัจจุบัน
- **เดือน** — ปฏิทินรายเดือน วันที่มีงานหลายรายการจะซ้อนกันและแสดงเลขจำนวนบนช่องวันที่
- **ปี** — ตาราง 12 เดือน ใช้ระบบซ้อนและเลขจำนวนแบบเดียวกัน แตะที่เดือนเพื่อเข้าไปดูมุมมองเดือน
- แตะวันไหนก็ได้เพื่อดูงานและกิจวัตรของวันนั้น

### กล่องไอเดีย (Idea Box)
- เขียนไอเดียหย่อนลงกล่องได้ตลอด **โดยไม่ต้องเปิดกล่อง**
- ไอเดียข้างในจะไม่แสดงจนกว่าจะกดเปิดกล่อง
- เมื่อเปิดกล่องแล้วเลือกโน้ตได้ทีละหลายใบเพื่อ **ย้ายไปเป็น Task** พร้อมเลือกโฟลเดอร์ปลายทางและกำหนดส่ง

### กิจวัตร (Routines)
- สิ่งที่ทำซ้ำ ๆ เช่น ตารางเรียน — เลือกวันในสัปดาห์และช่วงเวลาเริ่ม–จบ
- กำหนดช่วงวันที่เริ่ม/สิ้นสุดของกิจวัตรได้ (เช่น เฉพาะภาคเรียนนี้)
- แสดงในหน้าแรกส่วนที่ไม่มีกำหนดส่ง และแสดงเป็นบล็อกในตารางสัปดาห์/เดือน/ปี
- ตั้งการเตือนแบบซ้ำทุกสัปดาห์ได้เหมือนงาน

### ข้อมูลและการสำรอง
- เก็บด้วย SQLite (`sqflite`) ทั้งหมด — ใช้งานออฟไลน์ได้เต็มรูปแบบ
- **Export** เป็นไฟล์ JSON (บันทึกลงเครื่อง หรือแชร์ไปแอปอื่น)
- **Import** เลือกได้ว่าจะ *รวมข้อมูล* กับของเดิม หรือ *เขียนทับ* ทั้งหมด พร้อมตั้งการเตือนใหม่ให้อัตโนมัติ

## โครงสร้างโปรเจกต์

```
lib/
├── data/          โมเดล, SQLite (database/repository), export-import
├── services/      การแจ้งเตือน+ปลุก, การเลือกเสียงจากเครื่อง
├── state/         AppState (ChangeNotifier) รวมข้อมูลและตรรกะทั้งแอป
├── ui/
│   ├── calendar/  มุมมองสัปดาห์ / เดือน / ปี
│   └── widgets/   การ์ดงาน, ตัวตั้งการเตือน, ชิ้นส่วนที่ใช้ซ้ำ
└── utils/         การแบ่งช่วงกำหนดส่ง และรูปแบบวันที่ภาษาไทย
```

## Build APK

```bash
flutter build apk --release              # ไฟล์รวมทุกสถาปัตยกรรม
flutter build apk --release --split-per-abi
```

โดยค่าเริ่มต้น release build จะเซ็นด้วย debug keystore เพื่อให้ติดตั้งทดสอบได้ทันที
หากต้องการเซ็นด้วย key ของตัวเอง ให้สร้าง `android/key.properties`

```properties
storePassword=...
keyPassword=...
keyAlias=...
storeFile=/path/to/keystore.jks
```

## ดาวน์โหลด

APK ของแต่ละเวอร์ชันอยู่ที่หน้า [Releases](../../releases) — สร้างอัตโนมัติจาก GitHub Actions
เมื่อ push แท็ก `v*` หรือสั่งรัน workflow **Release APK** ด้วยตัวเอง

## สิทธิ์ที่แอปขอบน Android

| สิทธิ์ | ใช้ทำอะไร |
| --- | --- |
| `POST_NOTIFICATIONS` | แสดงการแจ้งเตือนก่อนถึงกำหนด |
| `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | ให้การเตือนและปลุกตรงเวลา |
| `RECEIVE_BOOT_COMPLETED` | ตั้งการเตือนกลับคืนหลังเครื่องรีบูต |
| `USE_FULL_SCREEN_INTENT` | แสดงหน้าปลุกเต็มจอ |
| `VIBRATE`, `WAKE_LOCK` | สั่นและปลุกหน้าจอตอนแจ้งเตือน |
