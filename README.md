# Ourobask

แอป Flutter สำหรับเก็บ **Task / Work / Idea** พร้อมระบบแจ้งเตือนและปลุกตามกำหนดส่ง
ข้อมูลทั้งหมดเก็บในเครื่องด้วย **SQLite** และ Export / Import เป็นไฟล์ JSON ได้

## ความสามารถ

### งาน (Task)
- สร้างงานได้เหมือนโน้ต มีชื่อเรื่อง + รายละเอียด
- **วันที่และเวลาเป็นทางเลือกทั้งคู่**
  - ไม่ระบุวัน → เป็นงานไม่มีกำหนดส่ง
  - ระบุวันแต่ไม่ระบุเวลา → นับเป็น **ทั้งวัน (all-day)** และใช้ 09:00 เป็นเวลาอ้างอิงของการเตือน
  - ระบุเวลาด้วย → กำหนดระยะเวลาของงานเพิ่มได้
- ระดับความสำคัญ สี และสถานะเสร็จสิ้น
- **สวิตช์เปิด/ปิดการแจ้งเตือนของงานได้จากรายการงานเลย** ไม่ต้องเข้าไปในหน้างาน
  (สวิตช์จะขึ้นเฉพาะงานที่ตั้งการเตือนไว้แล้ว และคุมการเตือนทุกรายการของงานนั้นพร้อมกัน)

### ประวัติงานที่ทำเสร็จแล้ว
- เปิดจากปุ่ม **ประวัติ** (ไอคอนนาฬิกาย้อนกลับ) บนแถบด้านบนของหน้าแรก
- แสดงงานที่ทำเสร็จแล้วทั้งหมด **จัดกลุ่มตามวันที่ทำเสร็จ** พร้อมเวลาที่ติ๊กว่าเสร็จ
- กด **กู้คืน** เพื่อเอางานกลับมาทำต่อ (ล้างสถานะเสร็จและตั้งการเตือนใหม่ให้อัตโนมัติ)
- ลบทีละรายการหรือล้างประวัติทั้งหมดถาวรได้
- **เก็บงานที่ทำเสร็จไว้สูงสุด 30 วัน** แล้วล้างออกอัตโนมัติทุกครั้งที่เปิดแอป
  แต่ละรายการบอกไว้ด้วยว่าเหลืออีกกี่วันก่อนถูกล้าง

### เควสเก็บเงิน (Quest)
- งานอีกประเภทหนึ่งสำหรับ **วางแผนเก็บเงิน** — เลือกประเภทเป็น "เควสเก็บเงิน" ในหน้าสร้างงาน
- **ต้องระบุจำนวนเงินเป้าหมาย** แล้วทยอยหยอดเงินเข้าไปทีละครั้ง (ถอนออกก็ได้)
- แสดง **แถบความคืบหน้าของยอดเงินในรายการงาน** พร้อมยอดที่เก็บได้ / เป้าหมาย และเปอร์เซ็นต์
- การ์ดโฟลเดอร์งานและหน้ารายละเอียดโฟลเดอร์แสดง **ยอดเงินรวมของทุกเควสในโฟลเดอร์** เป็นแถบความคืบหน้า
  และหน้าแรกแสดงยอดรวมของทั้งแอป
- เก็บครบเป้าเมื่อไหร่ เควสจะถูกทำเครื่องหมายว่าเสร็จให้เอง (ลบรายการเงินออกก็ย้อนกลับให้)
- เก็บประวัติการหยอดเงินทุกครั้ง พร้อมบันทึกช่วยจำและวันที่

### โฟลเดอร์งาน (Work Project)
- สร้างโปรเจกต์เป็นโฟลเดอร์ครอบงานอีกชั้น เลือกไอคอนและสีได้
- หน้า **งาน** แสดงโปรเจกต์เป็น card view พร้อมความคืบหน้า จำนวนงานที่ค้าง และยอดเงินรวมของเควส
- ลบโฟลเดอร์ได้ทั้งแบบเก็บงานไว้หรือลบงานไปพร้อมกัน

### การแจ้งเตือนและปลุก
- ตั้งเตือนล่วงหน้าได้หลายรายการต่อหนึ่งงาน โดย **เลือกเวลาเตือนจาก dropdown** เช่น ก่อน 1 ชั่วโมง / 1 วัน / 1 สัปดาห์
  หรือเลือก "กำหนดเอง" เพื่อระบุเป็นจำนวนนาที
- แต่ละการเตือนเลือกได้ว่าเป็น **แจ้งเตือนธรรมดา** หรือ **ปลุก (alarm)**
- ปลุกเลือกเสียงจากเครื่องผู้ใช้ได้ 2 ทาง
  - เสียงในระบบ (ตัวเลือกเสียงมาตรฐานของ Android)
  - ไฟล์เสียงในเครื่อง — ไฟล์จะถูกคัดลอกเข้าโฟลเดอร์แอปและแปลงเป็น `content://` ผ่าน FileProvider เพื่อให้ระบบแจ้งเตือนอ่านได้
- ลองฟังเสียงก่อนใช้จริงได้ (เล่นด้วยระดับเสียงของ alarm)
- **หน้าแรกมีสวิตช์เปิด/ปิดการเตือนแต่ละรายการได้อิสระ โดยไม่ต้องลบการเตือนทิ้ง**

### หน้าแรก
เรียงงานตามความใกล้ของกำหนดส่ง แบ่ง Section ตามลำดับ

1. เลยกำหนดแล้ว
2. ครบกำหนดวันนี้
3. ภายใน 1 วัน
4. ภายใน 3 วัน
5. ภายใน 1 สัปดาห์
6. ภายใน 2 สัปดาห์
7. ภายใน 1 เดือน
8. มากกว่า 1 เดือน
9. กิจวัตรที่ทำซ้ำ + งานที่ไม่มีกำหนดส่ง

ด้านบนมีกล่องรวม **การแจ้งเตือน & ปลุก** ทั้งหมดพร้อมสวิตช์เปิด/ปิด

### ปฏิทิน (View)
- **สัปดาห์** — ตารางเวลาแบบตารางเรียน มีหลักชั่วโมง 00:00–23:00 งานที่เวลาทับกันจะแสดงเคียงกัน มีแถวงานทั้งวันด้านบนและเส้นบอกเวลาปัจจุบัน
- **เดือน** — ปฏิทินรายเดือน วันที่มีงานหลายรายการจะซ้อนกันและแสดงเลขจำนวนบนช่องวันที่
- **ปี** — ตาราง 12 เดือน ใช้ระบบซ้อนและเลขจำนวนแบบเดียวกัน แตะที่เดือนเพื่อเข้าไปดูมุมมองเดือน
- แตะวันไหนก็ได้เพื่อดูงานและกิจวัตรของวันนั้น
- **แตะที่ช่วงเวลาบนหัวปฏิทิน** เพื่อเปิดรายการสัปดาห์/เดือน/ปี แล้วกระโดดข้ามไปยังช่วงที่ต้องการได้ทันที

### กล่องไอเดีย (Idea Box)
- เขียนไอเดียหย่อนลงกล่องได้ตลอด **โดยไม่ต้องเปิดกล่อง**
- ตอนกล่องปิดอยู่ ปุ่ม **หย่อนไอเดีย** จะอยู่กลางจอและอยู่หน้ากล่อง
  ส่วนปุ่ม **เปิดกล่อง** เป็นปุ่มเล็กกว่าอยู่ใต้ปุ่มหย่อนไอเดีย
- ไอเดียข้างในจะไม่แสดงจนกว่าจะกดเปิดกล่อง
- เมื่อเปิดกล่องแล้วเลือกโน้ตได้ทีละหลายใบเพื่อ **ย้ายไปเป็น Task** พร้อมเลือกโฟลเดอร์ปลายทางและกำหนดส่ง

### กิจวัตร (Routines)
- สิ่งที่ทำซ้ำ ๆ เช่น ตารางเรียน — เลือกวันในสัปดาห์และช่วงเวลาเริ่ม–จบ
- **ทำซ้ำได้ 2 รูปแบบ**
  - *ทุกสัปดาห์* — เลือกวันในสัปดาห์ (จ–อา)
  - *ทุกเดือน* — **ระบุวันที่ของเดือน** ได้หลายวัน เช่น ทุกวันที่ 1 และ 25
    (เดือนที่ไม่มีวันที่นั้น เช่น 31 ในเดือนกุมภาพันธ์ จะเลื่อนมาเป็นวันสุดท้ายของเดือนให้อัตโนมัติ)
- **ใช้เป็นแผนเก็บเงินของเควสได้** — ผูกกิจวัตรกับเควสหนึ่งอันแล้วระบุยอดเงินต่อรอบ
  ถึงวันที่กำหนดจะเตือนให้ และกดปุ่มบันทึกเงินเข้าเควสได้จากรายการกิจวัตรเลย
  พร้อมประเมินให้ว่าจะเก็บครบเป้าในอีกกี่เดือน
- กำหนดช่วงวันที่เริ่ม/สิ้นสุดของกิจวัตรได้ (เช่น เฉพาะภาคเรียนนี้)
- แสดงในหน้าแรกส่วนที่ไม่มีกำหนดส่ง และแสดงเป็นบล็อกในตารางสัปดาห์/เดือน/ปี
- ตั้งการเตือนแบบซ้ำทุกสัปดาห์หรือทุกเดือนได้เหมือนงาน

### ตรวจสอบเวอร์ชันและอัปเดตในแอป
- ตรวจรีลีสใหม่จาก **GitHub Releases** ของโปรเจกต์นี้โดยตรง (ไม่ต้องใช้ token)
- ตรวจให้อัตโนมัติเมื่อเปิดแอป (ไม่เกินวันละครั้ง) หรือกดตรวจเองได้ที่ **ตั้งค่า → ตรวจสอบอัปเดตแอป**
- มีเวอร์ชันใหม่จะขึ้นแผ่นสรุปพร้อมรายละเอียดรีลีส เลือกได้ว่าจะอัปเดต เลื่อนไว้ก่อน หรือข้ามเวอร์ชันนั้น
- กดอัปเดตแล้ว **ดาวน์โหลด APK พร้อมแถบความคืบหน้าแล้วส่งให้ตัวติดตั้งของ Android ต่อในแอปเลย**
  โดยเลือกไฟล์ที่ตรงกับสถาปัตยกรรมของเครื่องให้อัตโนมัติ (ไฟล์เล็กกว่าไฟล์รวม)
- ถ้ายังไม่ได้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" แอปจะพาไปหน้าตั้งค่าของสิทธิ์นั้นให้

### ข้อมูลและการสำรอง
- เก็บด้วย SQLite (`sqflite`) ทั้งหมด — ใช้งานออฟไลน์ได้เต็มรูปแบบ
- **Export** เป็นไฟล์ JSON (บันทึกลงเครื่อง หรือแชร์ไปแอปอื่น)
- **Import** เลือกได้ว่าจะ *รวมข้อมูล* กับของเดิม หรือ *เขียนทับ* ทั้งหมด พร้อมตั้งการเตือนใหม่ให้อัตโนมัติ
- ไฟล์สำรองเวอร์ชันเก่า (format v1) ยังนำเข้าได้ตามปกติ และฐานข้อมูลเดิมจะถูกอัปเกรดให้เองเมื่อเปิดแอปเวอร์ชันใหม่

## โครงสร้างโปรเจกต์

```
lib/
├── app_info.dart  ชื่อ/เวอร์ชันของแอปและที่อยู่ repo สำหรับตรวจอัปเดต
├── data/          โมเดล, SQLite (database/repository), export-import
├── services/      การแจ้งเตือน+ปลุก, การเลือกเสียงจากเครื่อง, ตรวจ+ติดตั้งอัปเดต
├── state/         AppState (ChangeNotifier) รวมข้อมูลและตรรกะทั้งแอป
├── ui/
│   ├── calendar/  มุมมองสัปดาห์ / เดือน / ปี และแผ่นเลือกช่วงเวลาเพื่อกระโดดข้าม
│   └── widgets/   การ์ดงาน, ตัวตั้งการเตือน, ชิ้นส่วนที่ใช้ซ้ำ
└── utils/         การแบ่งช่วงกำหนดส่ง, อายุของประวัติงาน และรูปแบบวันที่ภาษาไทย
```

## การพัฒนา

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## Build APK

```bash
flutter build apk --release              # ไฟล์รวมทุกสถาปัตยกรรม
flutter build apk --release --split-per-abi
```

โดยค่าเริ่มต้น release build จะเซ็นด้วย debug keystore เพื่อให้ติดตั้งทดสอบได้ทันที
หากต้องการเซ็นด้วย key ของตัวเอง ให้สร้าง `android/key.properties`

```properties
storePassword=...
keyPassword=...
keyAlias=...
storeFile=/path/to/keystore.jks
```

## ดาวน์โหลด

APK ของแต่ละเวอร์ชันอยู่ที่หน้า [Releases](../../releases) — สร้างอัตโนมัติจาก GitHub Actions
เมื่อ push แท็ก `v*` หรือสั่งรัน workflow **Release APK** ด้วยตัวเอง

## สิทธิ์ที่แอปขอบน Android

| สิทธิ์ | ใช้ทำอะไร |
| --- | --- |
| `POST_NOTIFICATIONS` | แสดงการแจ้งเตือนก่อนถึงกำหนด |
| `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | ให้การเตือนและปลุกตรงเวลา |
| `RECEIVE_BOOT_COMPLETED` | ตั้งการเตือนกลับคืนหลังเครื่องรีบูต |
| `USE_FULL_SCREEN_INTENT` | แสดงหน้าปลุกเต็มจอ |
| `VIBRATE`, `WAKE_LOCK` | สั่นและปลุกหน้าจอตอนแจ้งเตือน |
| `INTERNET` | ตรวจสอบและดาวน์โหลดรีลีสใหม่จาก GitHub |
| `REQUEST_INSTALL_PACKAGES` | ส่งไฟล์ APK ที่ดาวน์โหลดมาให้ตัวติดตั้งของระบบ (ผู้ใช้ยังต้องกดยืนยันเอง) |
